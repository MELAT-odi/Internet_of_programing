# Personal Portfolio Website

This is my personal portfolio website, created using HTML only.

It introduces my background, education, skills, projects, interests, and contact information.

Website Pages

## The website contains six main pages:

Home: A welcome page introducing me and my personal goals.

About Me: Information about my background, interests, values, and ambitions.

Skills & Education: My educational background, technical skills, and learning progress.

Projects & Achievements: Examples of projects, learning experiences, and achievements.

My Media & Interests: My interests, favourite media, and useful learning resources.

Contact Me: Contact information and a form for visitors to send messages.
